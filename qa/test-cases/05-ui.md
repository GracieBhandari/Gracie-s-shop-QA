# Test Cases: UI, Responsive Design, and Browsers

Covers layout at different screen sizes, browser compatibility, keyboard use, and error states.
Screen sizes: [test-data.md § 7](../test-data/test-data.md#7-screen-sizes). To test phone and tablet sizes in Chrome, open Developer Tools (`Cmd + Option + I`) and click the device toolbar icon.

**Status values:** Not run · Pass · Fail · Blocked. Record what actually happened in **Actual Result**, and link the bug report (e.g. BUG-001) for any failure.
